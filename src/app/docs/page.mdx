# Feyo documentation

Feyo is an independent, open-source project building Stellar-powered stablecoin payment infrastructure for products, developers, and AI agents.

> **Project status:** This documentation foundation is live. The payment execution, developer API, and MCP surfaces described here are design targets unless a page explicitly marks them as implemented.

## Start here

- [Getting started](/docs/getting-started) — understand the repository and current development workflow.
- [Architecture](/docs/architecture) — see the intended system boundaries and trust model.
- [Stellar](/docs/stellar) — learn how Stellar fits into the payment model.

## What Feyo is building

Feyo aims to make stablecoin payments easier to integrate without hiding the important parts: authorization, transaction identity, status verification, and operational boundaries.

The eventual platform includes a web application, a developer API, and an MCP server for agent-driven workflows. Nigerian bank payouts through regulated providers are a planned extension, not a current capability.

## Status vocabulary

- **Implemented:** present in this repository and verified by the project checks.
- **Work in progress:** actively being shaped or implemented, but not a stable public contract.
- **Planned:** part of the product direction; do not depend on it yet.

See the [roadmap](/docs/roadmap) for the current boundary.
