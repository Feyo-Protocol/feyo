# Feyo project instructions for Claude and other agents

**Start by reading `AGENTS.md` at the repository root.** Follow its security restrictions and workflow. Then read `docs/PROJECT_HANDOFF.md` (current state), `docs/PRODUCT_ROADMAP.md` (long-term direction), `docs/ARCHITECTURE_DECISIONS.md` (design rationale) and `docs/MAINTAINER_PLAYBOOK.md` (community/Wave procedures).

Preserve source code, branch and contributor work. Do not call a feature merged or deployed without evidence. No private-key custody, unreviewed signing/broadcast, fabricated settlement, Mainnet or assumed Drips approval. Work within the named issue. Record tests, risks, branch/commit and the precise next step in the handoff on completion.

This pointer is intentionally short so rules stay in one place. If instructions conflict, report the conflict instead of silently guessing.
